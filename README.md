# B2C Excellence Award

Published dashboard for AIESEC in Egypt, offline S1 July–December 2026.

**These are saved results captured on 9 November 2026, not a live ROUH data feed.**

Open index.html to see the standings. Offline leads and Customer Interviews are Unknown and excluded, leaving provisional points out of 85. Event counts include summits, fairs and the user-confirmed named events, with at least 30 offline SUs per LC. Negative growth earns zero points. Growth is provisional because the historical July–November totals are not channel-split and current November is incomplete.

The ROUH live setup link opens a browser bookmark launcher. That version can refresh while open on a signed-in ROUH page; the GitHub Pages site cannot use the ROUH login session directly. Historical baseline values remain a fixed extract.

To publish, select Settings → Pages → Deploy from a branch → main → /(root). GitHub Pages will serve index.html.

To update the published snapshot, replace index.html and current-scores.csv with a newly verified extract. Never commit passwords, session cookies or API keys.

Sources: https://rouh.aiesec.org.eg/mc/b2c-mkt/ and the provided 3.2 B2C - LCs Planning historical tab. Full scoring rules and source details are available in the dashboard.
